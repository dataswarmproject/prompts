# Quick Start Guide for Marketers

**Supercharge your marketing workflow with AI in 30 minutes.**

## Get Started in 3 Steps

### Step 1: Choose Your Tools (5 min)

**Primary Tool**: ChatGPT Plus or Claude Pro
- Both: $20/month
- ChatGPT: Better for image generation (DALL-E)
- Claude: Better for long-form content

**Sign up**:
- ChatGPT: https://chat.openai.com
- Claude: https://claude.ai

**Browser Extension**: Monica AI or Merlin (for quick access anywhere)

---

### Step 2: First Marketing Tasks (15 min)

#### Task 1: Social Media Post
```
Create 5 LinkedIn posts about [your product/topic]

Audience: [B2B SaaS marketers]
Tone: [Professional but conversational]
Goal: [Drive website traffic]

For each post include:
- Hook (first line to stop the scroll)
- Value/insight
- Call-to-action
- Relevant hashtags (5-8)

Each post should be 150-200 words.
```

#### Task 2: Email Campaign
```
Write a 3-email welcome sequence for new subscribers to [your product]

Audience: [small business owners]
Brand voice: [Friendly, helpful, not sales-y]

Email 1 (Day 0): Welcome and set expectations
Email 2 (Day 3): Quick win / useful tip
Email 3 (Day 7): Social proof and gentle CTA

For each:
- Subject line (A/B test options)
- Preview text
- Body (200-300 words)
- CTA
```

#### Task 3: Content Ideas
```
Generate 20 blog post ideas for [your industry]

Target audience: [description]
Topics to cover: [main themes]
Goals: [SEO traffic + thought leadership]

For each idea provide:
- Title
- Target keyword
- Brief outline (3-5 main points)
- Estimated word count
```

#### Create Saved Prompts

**Content Calendar**:

Create a monthly content calendar for [channel]

Themes: [your themes]

```
Write 5 variations of ad copy for [product/service]

Platform: [Facebook/Google/LinkedIn]
Objective: [conversions/traffic/awareness]
Audience: [specific target]
Character limit: [depends on platform]

Highlight:
- Main benefit
- Unique value proposition
- Pain point solution
- Urgency/social proof
```

**Competitor Analysis**:
```
Analyze this competitor's website/content:
[URL or description]

Compare to our brand: [your brand]

Identify:
- Messaging strategy
- Target audience approach
- Unique positioning
- Content themes
- What they do well
- Opportunities for us
```

## Essential Marketing Workflows

### Workflow 1: Campaign Launch

```bash
Day 1: Strategy
→ "Create marketing strategy for [campaign goal]"
  - Target audience definition
  - Key messages
  - Channel mix
  - Success metrics

Day 2: Content Creation
→ "Generate campaign content" (using strategy)
  - Ad copy variations
  - Landing page copy
  - Email sequence
  - Social posts

Day 3: Visual Assets
→ "Create DALL-E prompts for campaign visuals"
→ Generate images
→ "Write alt text for each image"

Day 4: Review & Optimize
→ "Review all campaign materials for consistency"
→ "Suggest A/B test variations"
```

### Workflow 2: Content Production

```
Step 1: Research
"Research trending topics in [your industry]"
"Identify content gaps our competitors aren't covering"

Step 2: Ideation
"Generate 10 content ideas based on research"
"Create detailed outline for top 3 ideas"

Step 3: Creation
"Write full blog post based on outline #1"
"Optimize for SEO keyword: [keyword]"

Step 4: Distribution
"Repurpose blog post into:
- Twitter thread
- LinkedIn post
- Instagram carousel script
- Email newsletter section"

Step 5: Amplification
"Create promotion plan for this content"
```

### Workflow 3: Customer Research

```
Input: Customer interview transcripts, reviews, support tickets

Prompt:
"Analyze these customer conversations and identify:

1. Common pain points (top 5)
2. Language they use to describe problems
3. Desired outcomes
4. Objections to buying
5. Unexpected use cases
6. Feature requests

[Paste customer data]

Create marketing implications for each insight."
```

## Power Prompts for Marketers

### SEO Content
```
Write SEO-optimized article about [topic]

Primary keyword: [keyword] (1-2% density)
Secondary keywords: [list]
Target word count: 1500-2000

Structure:
- Title (include keyword, <60 chars)
- Meta description (<160 chars)
- H1 with keyword
- Introduction with keyword in first 100 words
- H2/H3 with LSI keywords
- FAQ section (People Also Ask)
- Conclusion with CTA

Tone: [Authoritative but accessible]
Reading level: [8th grade]
```

### Landing Page Copy
```
Write high-converting landing page copy for [product/offer]

Above the fold:
- Headline (benefit-driven, <10 words)
- Subheadline (expand on benefit)
- Hero CTA

Problem section:
- Agitate pain points (3-5)
- Show empathy

Solution section:
- How product solves each pain point
- Key features → benefits

Social proof:
- Testimonial suggestions
- Trust indicators

Features/Benefits:
- 3-5 features with icons and benefits

How it works:
- 3 simple steps

Pricing:
- Value-based presentation
- Handle common objections

Final CTA:
- Urgency/scarcity
- Risk reversal
```

### Brand Voice Development
```
Develop brand voice guidelines for [company]

Company: [description]
Values: [core values]
Audience: [target customer]
Personality: [3-5 adjectives]

Create:
1. Voice attributes (4-5)
   For each: Definition, Do's, Don'ts

2. Tone variations:
   - Social media
   - Website
   - Email
   - Ads
   - Customer service

3. Word bank:
   - Words we use often
   - Words we avoid

4. Example rewrites:
   "We're excited to announce..."
   "Sorry for the inconvenience..."
   "Check out our new feature..."

Show before (generic) and after (branded)
```

## Platform-Specific Tips

### LinkedIn
```
LinkedIn post about [topic]

Format:
- Hook (curiosity or bold statement)
- Personal story or data point
- 3-5 key insights (bullets or numbers)
- Lesson learned
- Question for engagement

Length: 150-200 words
Tone: Professional but personal
Hashtags: 3-5 relevant

End with: "What's your experience with [topic]? 👇"
```

### Instagram
```
Instagram carousel post (6-8 slides)

Topic: [your topic]
Goal: [educate/inspire/entertain]

Slide 1: Eye-catching title
Slides 2-7: One insight per slide
Slide 8: CTA and follow

For each slide:
- Main text (3-7 words, large)
- Supporting text if needed
- Design style: [minimalist/bold/playful]

Caption:
- Expand on carousel content
- Story or context
- CTA
- Hashtags (20-30 mix)
```

### Twitter/X
```
Twitter thread about [topic] (8-10 tweets)

Tweet 1: Hook (make them want to read)
Example: "I spent $50k on ads and learned these 7 lessons:"

Tweets 2-9: One lesson per tweet
- Each tweet standalone value
- Use numbers, bullets, or spacing
- 1-2 sentences each

Tweet 10: Summary + CTA
- Follow for more
- Link to deep dive
- Question for replies

Thread style: [conversational/tactical/storytelling]
```

## A/B Testing with AI

```
Create A/B test variations for [element]

Control: [current version]

Test focus: [headline/CTA/offer/image]

Generate 5 variations testing:
1. Benefit-focused vs feature-focused
2. Long vs short
3. Urgency vs social proof
4. Emotional vs rational
5. Direct vs indirect

For each:
- Variation text
- Hypothesis (why it might win)
- What metric to track
- Expected lift

Recommend which to test first.
```

## Common Marketing Tasks

### Product Launch
```
Create product launch marketing plan for [product]

Product: [description]
Target: [audience]
Goal: [100 customers in 30 days]
Budget: [$X]

Plan:
1. Pre-launch (2 weeks):
   - Teaser campaign
   - Waitlist building
   - Influencer outreach

2. Launch week:
   - Announcement sequence
   - Launch offer
   - Media outreach

3. Post-launch (2 weeks):
   - User testimonials
   - Results sharing
   - Retargeting

For each phase:
- Channels to use
- Content needed
- Key messages
- Timeline
```

### Customer Persona
```
Create detailed customer persona for [product]

Based on:
- [Existing customer data]
- [Market research]
- [Competitor analysis]

Include:
- Demographics
- Job title and role
- Goals and motivations
- Pain points and challenges
- Where they hang out (channels)
- Information sources they trust
- Buying process
- Objections and concerns
- Key messages that resonate

Make it specific and actionable.
```

### Competitive Analysis
```
Analyze top 3 competitors in [market]

Competitors: [list]
Our position: [your brand]

For each competitor analyze:
1. Positioning and messaging
2. Target audience
3. Pricing strategy
4. Marketing channels
5. Content strategy
6. Strengths and weaknesses
7. What they do better than us
8. What we do better

Provide:
- Comparison matrix
- Opportunities for differentiation
- Threats to watch
- Action recommendations
```
