# Quick Start Guide for Designers

**Integrate AI into your design workflow in 30 minutes.**

## Getting Started

### Step 1: Choose Your Tools (5 min)

**For UI/UX Design**:
- ChatGPT Plus or Claude Pro ($20/mo)

**For Visual Design**:
- Midjourney ($10-60/mo) - Best quality
- DALL-E via ChatGPT Plus ($20/mo) - Integrated
- Or Stable Diffusion (free, via Hugging Face)

**Quick Setup**:
1. Sign up for ChatGPT Plus: https://chat.openai.com
2. For Midjourney: Join Discord → Subscribe
3. Install Figma (if not already)

---

### Step 2: First Design Tasks (15 min)

#### Task 1: Generate Design Concepts
```
Generate 5 design concepts for [project type]

Project: [Mobile app for fitness tracking]
Target users: [25-40 year olds, health-conscious]
Brand personality: [Modern, energetic, trustworthy]
Key features to highlight: [Workout tracking, progress charts, social features]

For each concept describe:
- Overall visual direction
- Color palette (5-6 colors with hex codes)
- Typography choices (font pairings)
- Layout approach
- Unique visual elements
- Mood/feeling it creates
```

#### Task 2: Create User Flow
```
Design user flow for [specific task]

Task: [New user onboarding]
App type: [E-commerce mobile app]
Goal: [Get users to complete profile and make first purchase]

Create flow showing:
- Entry point
- Each screen/step
- User actions required
- Decision points
- Success state
- Alternative paths
- Error handling

Identify potential friction points and suggest improvements.
```

#### Task 3: Generate Visual Assets
```
Create DALL-E prompts for [project visuals]

Need: [Hero image for SaaS landing page]
Style: [Modern, clean, professional]
Colors: [Blues and whites, minimal]
Elements: [Abstract representation of data/analytics]
Mood: [Trustworthy, innovative]

Generate 3-5 detailed prompts optimized for best results.
Then use them in ChatGPT to generate images.
```

### Step 3: Build Your Design Workflow (10 min)

Save these prompts for regular use:

**Design System Creation**
```
Create design system foundation for [brand]

Brand: [name and description]
Personality: [3-5 adjectives]
Industry: [your industry]

Define:
1. Color System:
   - Primary (3 shades)
   - Secondary (3 shades)
   - Neutrals (grays, 7-step scale)
   - Semantic (success, warning, error)
   - All with hex codes and usage

2. Typography:
   - Primary font (headings)
   - Secondary font (body)
   - Mono font (code)
   - Type scale (8 sizes)
   - Line heights
   - Font weights to use

3. Spacing Scale:
   - Base unit
   - Scale (4px, 8px, 16px, 24px, 32px, 48px, 64px)

4. Elevation:
   - 5 levels of shadow
   - When to use each

5. Border Radius:
   - Scale (0, 4px, 8px, 16px, full)

6. Grid System:
   - Columns (mobile/tablet/desktop)
   - Gutters
   - Margins
```

## Design Workflows

### Workflow 1: UI Design Project

```
Day 1: Discovery & Strategy
→ "Analyze competitors' designs for [product type]"
→ "Create user personas for [product]"
→ "Define information architecture"

Day 2: Concepts
→ "Generate 3 design directions"
→ "Create mood boards for each direction"
→ "Recommend design direction with rationale"

Day 3: Wireframes
→ "Create wireframe structure for [key screens]"
→ "Optimize user flow for [goal]"

Day 4: Visual Design
→ "Create high-fidelity mockups based on wireframes"
→ "Design component variations"

Day 5: Specifications
→ "Generate design specifications for developers"
→ "Create component documentation"
```

### Workflow 2: Rapid Prototyping

```
Step 1: Concept (15 min)
"Design a mobile app interface for [purpose]
Include: [screens needed]
Style: [visual direction]"

Step 2: Iterate (30 min)
"Improve this design:
[Paste AI description or upload screenshot]

Focus on:
- Visual hierarchy
- Whitespace
- Accessibility
- Modern design trends"

Step 3: Variants (15 min)
"Create 3 color scheme variations"
"Show dark mode version"
"Design responsive breakpoints"

Step 4: Present (15 min)
"Create presentation deck explaining:
- Design decisions
- User flow logic
- Accessibility features
- Next steps"
```

### Workflow 3: Design System Component

```
Create [component type] component

Component: [Button/Card/Modal/Form Input]

Define:
1. Anatomy:
   - Parts of component
   - Required vs optional elements

2. Variants:
   - Primary, Secondary, Tertiary
   - Sizes: Small, Medium, Large
   - States: Default, Hover, Active, Disabled, Loading

3. Specifications:
   - Dimensions
   - Padding/Spacing
   - Typography
   - Colors
   - Borders/Shadows
   - Icons

4. Behavior:
   - Interactions
   - Animations (duration, easing)
   - Responsive behavior

5. Accessibility:
   - Contrast ratios
   - Keyboard navigation
   - Screen reader support
   - Focus states

6. Usage:
   - When to use
   - When not to use
   - Examples
   - Common mistakes
```

## Power Prompts for Designers

### Visual Design Concept
```
Design visual concept for [project]

Project: [Website redesign for tech startup]
Goal: [Convey innovation and trustworthiness]
Target audience: [B2B decision makers, 35-55 years old]

Create concept including:

1. Visual Direction:
   - Overall aesthetic
   - Design style (minimalist/bold/playful/etc.)
   - Inspiration references

2. Color Palette:
   - Primary color (hex + rationale)
   - Secondary colors (2-3)
   - Accent colors
   - Neutral grays
   - How colors convey brand

3. Typography:
   - Heading font (with alternatives)
   - Body font (with alternatives)
   - Why these pairings work
   - Type scale

4. Layout Approach:
   - Grid system
   - Use of whitespace
   - Visual hierarchy strategy

5. Visual Elements:
   - Photography style
   - Illustration style (if any)
   - Icon style
   - Graphic elements

6. Mood Board:
   - Describe 8-10 reference images
   - What each represents

Show how everything works together.
```

### UX Audit
```
Conduct UX audit of [product/website]

URL or description: [link or details]

Analyze:

1. First Impressions:
   - Clear value proposition?
   - Visual hierarchy effective?
   - Trustworthy appearance?

2. Navigation:
   - Intuitive menu structure?
   - Easy to find key features?
   - Breadcrumbs/wayfinding?

3. User Flows:
   - [Key flow 1: e.g., signup]
   - Friction points?
   - Unnecessary steps?
   - Clear CTAs?

4. Content:
   - Scannable?
   - Appropriate length?
   - Clear headings?
   - Good use of visuals?

5. Mobile Experience:
   - Responsive?
   - Touch targets adequate?
   - Readable text?

6. Accessibility:
   - Color contrast issues?
   - Alt text present?
   - Keyboard navigable?
   - Screen reader friendly?

7. Performance:
   - Loading feedback?
   - Perceived performance?

For each issue:
- Severity (Critical/High/Medium/Low)
- User impact
- Recommended fix
- Priority

Provide summary of top 10 issues to fix.
```

### Design Critique
```
Provide design critique for [design element]

Design: [description or paste screenshot]
Context: [where it's used]
Goal: [what it should accomplish]

Critique following:

1. Visual Design:
   - Aesthetics and polish
   - Color usage
   - Typography
   - Spacing and alignment
   - Visual hierarchy

2. User Experience:
   - Intuitiveness
   - Clarity of purpose
   - Ease of use
   - Error prevention

3. Accessibility:
   - Color contrast
   - Text readability
   - Touch/click targets
   - WCAG compliance

4. Consistency:
   - With design system
   - With platform patterns
   - Internal consistency

5. Improvements:
   - Specific suggestions
   - Alternative approaches
   - Quick wins
   - Long-term enhancements

Be constructive and specific. Explain reasoning.
```

## AI Image Generation Tips

### Midjourney Prompt Formula
```
[Subject] [Style] [Lighting] [Color] [Composition] [Quality]

Example:
"Modern workspace with laptop and coffee, minimalist style,
soft natural lighting, pastel blue and white colors,
centered composition, high quality photography, 8k, sharp focus"

Parameters to add:
--ar 16:9 (aspect ratio)
--v 6 (version 6)
--style raw (photorealistic)
--s 250 (stylization level)
```

### DALL-E 3 Prompt Tips
```
Be descriptive and specific:

"Create a hero image for a productivity app. Modern and clean design.
Show a stylized illustration of a person organizing tasks on a large
digital board. Use a color palette of soft blues (#4A90E2) and whites.
Include subtle gradients. The illustration should feel friendly and
approachable, not corporate. Flat design style with subtle shadows.
Person should be diverse and professional-looking. 16:9 aspect ratio."

Tips:
- Specify exact colors (hex codes)
- Mention art style explicitly
- Describe mood and feeling
- Give composition details
- Specify what to avoid
```

### Iterating on AI Images
```
Take AI image output and refine:

"Regenerate this image but:
- Make the colors more vibrant
- Change person's clothing to business casual
- Add more whitespace on the left
- Make the overall composition less busy
- Adjust lighting to be brighter
- Change aspect ratio to square"

Or:

"Keep the same composition but:
- Change art style from illustration to photography
- Make it feel more [mood]
- Adjust color scheme to [new colors]"
```

## Accessibility with AI

### WCAG Compliance Check
```
Check this design for WCAG 2.1 Level AA compliance:

[Describe design or paste screenshot]

Check:
1. Color Contrast:
   - Text on backgrounds (4.5:1 minimum)
   - Large text (3:1 minimum)
   - UI components (3:1 minimum)
   - Calculate and report ratios

2. Text:
   - Minimum size (16px body text)
   - Line height (1.5 minimum)
   - Paragraph spacing

3. Touch Targets:
   - Minimum 44x44 pixels
   - Adequate spacing

4. Focus Indicators:
   - Visible focus states
   - Sufficient contrast

5. Content:
   - Descriptive link text
   - Alt text strategy
   - Heading hierarchy

For each issue:
- What's wrong
- WCAG criterion violated
- How to fix (specific values)
- Suggested redesign
```
