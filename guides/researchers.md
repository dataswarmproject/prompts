# Quick Start Guide for Researchers

**Accelerate your research workflow with AI in 30 minutes.**

## Getting Started

### Step 1: Choose Your Tools (5 min)

**Best for Research**:
- **Claude Pro** ($20/mo): 200K context = 500 pages of text
- **Perplexity Pro** ($20/mo): Real-time search + citations
- **ChatGPT Plus** ($20/mo): General purpose

**Recommendation**: Start with Claude Pro for long documents

**Sign up**: https://claude.ai

**Optional**: Zotero + browser extension (free reference manager)

### Step 2: First Research Tasks (15 min)

#### Task 1: Literature Review
```
Conduct a literature review on [research topic]

Topic: [Your specific research question]
Field: [Your discipline]
Time period: [Last 5 years or specific range]
Key areas to cover:
- [Theme 1]
- [Theme 2]
- [Theme 3]

Provide:
1. Overview of current state of knowledge
2. Major research streams
3. Key findings and consensus
4. Contradictions or debates
5. Methodological approaches used
6. Gaps in literature
7. Theoretical frameworks applied
8. Suggestions for future research

Format with citations (though you'll need to verify/add real ones).
```

#### Task 2: Analyze Research Paper
```
Analyze this research paper:

[Paste paper text or upload PDF to Claude]

Provide:
1. Executive Summary (150 words)
2. Research Question(s)
3. Methodology:
   - Design
   - Sample
   - Procedures
   - Analysis
4. Key Findings (prioritized)
5. Theoretical Contribution
6. Practical Implications
7. Limitations
8. Strengths of the study
9. Weaknesses/concerns
10. How this relates to [my research area]
11. Follow-up research questions

Format for easy reference.
```

#### Task 3: Research Design Help
```
Help me design a study to investigate [research question]

Question: [Your specific question]
Field: [Discipline]
Current knowledge: [Brief background]
Resources available: [Time, budget, access]

Provide:
1. Appropriate research design (with justification)
2. Sampling strategy
   - Population
   - Method
   - Size (with power analysis considerations)
3. Data collection methods
   - What to measure/observe
   - Instruments needed
   - Procedures
4. Data analysis plan
   - Statistical tests or qualitative methods
   - Software needed
5. Timeline (realistic milestones)
6. Potential challenges and solutions
7. Ethical considerations
8. Alternative approaches

Make it actionable and detailed.
```

## Research Workflows

### Workflow 1: Paper Writing

```
Stage 1: Outline (Day 1)
→ "Create detailed outline for paper on [topic]"
  - Journal: [target journal]
  - Word limit: [count]
  - Sections needed

Stage 2: Literature Review (Day 2-3)
→ "Synthesize these papers into lit review"
  [Paste key papers]
→ "Identify gaps this research addresses"

Stage 3: Methods (Day 4)
→ "Write methods section for [study design]"
  - Clear procedures
  - Replicable
  - Appropriate detail

Stage 4: Results (Day 5)
→ "Help structure results section"
  [Share findings]
→ "Create table/figure descriptions"

Stage 5: Discussion (Day 6)
→ "Draft discussion section"
  - Interpret findings
  - Compare to literature
  - Implications
  - Limitations

Stage 6: Polish (Day 7)
→ "Review for clarity and flow"
→ "Check APA style compliance"
→ "Suggest improvements"
```

### Workflow 2: Grant Writing

```
Step 1: Significance
"Write significance section for grant:

Problem: [Issue you're addressing]
Current gap: [What's unknown]
Your approach: [How you'll address it]
Impact: [Why it matters]

Make compelling case for funding.
Target: [Funding agency]
Format: [Their requirements]"

Step 2: Innovation
"Articulate innovative aspects:
- Novel methodology
- New theoretical framework
- Unique approach
- Expected breakthroughs

Show how this advances field."

Step 3: Approach
"Detail research approach:
- Aims (3-4)
- For each aim:
  * Rationale
  * Methods
  * Expected results
  * Potential problems & solutions
  * Timeline

Make it feasible and rigorous."

Step 4: Budget Justification
"Write budget justification:
[Budget items]

Explain why each item necessary.
Show cost-effectiveness.
Justify personnel time."
```

### Workflow 3: Data Analysis Pipeline

```

Recommend:
- Handling strategy
- Transformations needed

"Conduct exploratory analysis:

- Visualizations needed"

- How to report results"

Step 4: Interpretation
"Interpret these results:

[Results]

Provide:
- What findings mean
- Practical significance
- Limitations
- Alternative explanations
- Next analyses needed"
```

## Power Prompts for Researchers

### Systematic Review
```
Help conduct systematic review on [topic]

Research question: [PICO format question]
Inclusion criteria:
- [Criterion 1]
- [Criterion 2]

Exclusion criteria:
- [Criterion 1]
- [Criterion 2]

Create:
1. Search strategy:
   - Databases to search
   - Search terms and combinations
   - Boolean operators

2. Screening process:
   - Title/abstract screening criteria
   - Full-text screening criteria

3. Data extraction plan:
   - What to extract from each paper
   - Coding scheme

4. Quality assessment:
   - Tool to use
   - Criteria to evaluate

5. Synthesis approach:
   - Meta-analysis feasible?
   - Narrative synthesis structure

6. PRISMA flowchart outline
```

### Qualitative Analysis
```
Help me analyze qualitative data:

Study: [Research question and context]
Data type: [Interviews/Focus groups/Observations]
Amount: [X transcripts]
Approach: [Thematic/Grounded theory/IPA]

Data sample:
[Paste 2-3 transcript excerpts]

Provide:
1. Initial coding:
   - Suggest codes for these excerpts
   - Coding strategy

2. Theme development:
   - How codes might group
   - Potential themes
   - Theme hierarchy

3. Analysis process:
   - Step-by-step approach
   - Software recommendations (NVivo/Atlas.ti)
   - Quality checks

4. Reporting:
   - How to present themes
   - Quote selection criteria
   - Ensuring rigor

Help me through iterative analysis process.
```

### Research Proposal
```
Develop research proposal for [topic]

Proposal for: [Dissertation/Grant/IRB]
Format: [Specific requirements]

Include:

1. Title
2. Abstract (250 words)
3. Introduction:
   - Background
   - Problem statement
   - Research gap
   - Purpose
   - Research questions/hypotheses
   - Significance

4. Literature Review:
   - Theoretical framework
   - Key concepts
   - Previous research
   - Gaps

5. Methodology:
   - Design and rationale
   - Participants
   - Measures/instruments
   - Procedures
   - Analysis plan
   - Timeline

6. Expected Outcomes:
   - Anticipated findings
   - Contribution to field

7. Limitations
8. References structure

Make it compelling and rigorous.
```

## Research-Specific Tasks

### Coding Qualitative Data
```
Help me code this interview transcript:

Research focus: [Topic]
Coding approach: [Deductive/Inductive]

[If deductive] Initial codebook:
- [Code 1]: [Definition]
- [Code 2]: [Definition]

Transcript excerpt:
[Paste section]

Provide:
1. Suggested codes for each segment
2. Justification for codes
3. New codes emerging (if inductive)
4. Memos/analytic notes
5. Questions to explore

Do this iteratively for transcript sections.
```

### Statistical Power Analysis
```
Calculate sample size needed:

Study design: [Description]
Effect size expected: [Based on literature]
Statistical test: [Test planned]
Alpha level: 0.05
Power desired: 0.80

Provide:
1. Required sample size
2. Justification for effect size estimate
3. Sensitivity analysis (if smaller sample)
4. Attrition considerations
5. Final recommended N
6. Code to run power analysis in [R/Python]
```

### Research Ethics
```
Identify ethical considerations for study:

Study: [Description]
Participants: [Population]
Procedures: [What participants do]
Data: [What you're collecting]

Address:
1. Informed consent:
   - What to include
   - Special considerations

2. Risks:
   - Potential risks identified
   - Mitigation strategies

3. Privacy/Confidentiality:
   - Data security measures
   - Anonymization approach
   - Storage plan

4. Vulnerable populations:
   - Special protections needed

5. IRB application:
   - Likely review level
   - Key points to address

Draft consent form outline.
```

## Best Practices

### Verification
- **Always verify AI-generated facts**
- **Check any statistics or citations**
- **Use AI as assistant, not authority**
- **Cross-reference with primary sources**

### Ethical Use
- **Disclose AI use per journal/institution policies**
- **Don't use AI for peer review** (usually prohibited)
- **Verify you have rights to share data with AI**
- **Don't share sensitive/proprietary data**

### Quality Control
- **Read and edit all AI content**
- **Ensure argument coherence**
- **Check methodology rigor**
- **Verify analysis appropriateness**
