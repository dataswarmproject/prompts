## ما هو MCP؟

**بروتوكول سياق النموذج (MCP)** هو بروتوكول مفتوح طورته Anthropic يتيح لمساعدي الذكاء الاصطناعي التفاعل بشكل آمن مع الموارد المحلية والبعيدة. تعمل خوادم MCP كجسور بين نماذج الذكاء الاصطناعي والأدوات الخارجية ومصادر البيانات والخدمات.

### الفوائد الرئيسية
- **التكامل الآمن**: وصول محكوم إلى الموارد الخارجية
- **القابلية للتوسع**: سهولة إنشاء خوادم مخصصة
- **التوحيد**: واجهة متسقة عبر الأدوات
- **قابلية التوسع**: من الملفات المحلية إلى أنظمة المؤسسات

### كيف يعمل
1. **خادم MCP**: يوفر الأدوات والموارد عبر بروتوكول موحد
2. **عميل MCP**: مساعد ذكاء اصطناعي يتصل بالخوادم
3. **البروتوكول**: طبقة اتصال موحدة
4. **النقل**: STDIO، SSE، HTTP، أو WebSocket

## الخوادم المرجعية الرسمية

تظهر هذه الخوادم ميزات MCP ويتم الحفاظ عليها بواسطة Anthropic:

| الخادم | الوصف | حالة الاستخدام |
|--------|--------|----------------|
| **Everything** | خادم مرجعي/اختباري مع موجهات وموارد وأدوات | الاختبار والتطوير |
| **Fetch** | جلب محتوى الويب وتحويله للاستخدام الفعال لـ LLM | كشط الويب، استرجاع المحتوى |
| **Filesystem** | عمليات ملفات آمنة مع ضوابط وصول قابلة للتكوين | إدارة الملفات، تحرير الكود |
| **Git** | أدوات لقراءة وبحث ومعالجة مستودعات Git | التحكم في الإصدار، مراجعة الكود |
| **Memory** | نظام ذاكرة دائم قائم على الرسم البياني للمعرفة | السياق طويل الأمد، تخزين المعرفة |
| **Sequential Thinking** | حل المشكلات الديناميكي والتأملي من خلال تسلسلات الفكر | التفكير المعقد، التخطيط |
| **Time** | قدرات تحويل الوقت والمنطقة الزمنية | الجدولة، حسابات الوقت |

**التثبيت**:
```bash
# Filesystem
npx @modelcontextprotocol/server-filesystem /path/to/directory

# Git
npx @modelcontextprotocol/server-git /path/to/repo

# Fetch
npx @modelcontextprotocol/server-fetch
```

## التثبيت والتكوين

### خطوات التثبيت العامة

1. **تثبيت خادم MCP**:
```bash
npm install @modelcontextprotocol/server-<name>
# أو
npx -y @modelcontextprotocol/server-<name>
```

2. **التكوين في عميلك** (مثال Claude Code):
```json
{
  "mcpServers": {
    "server-name": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-name"],
      "env": {
        "API_KEY": "your_api_key"
      }
    }
  }
}
```

3. **إعادة تشغيل عميلك**: أعد تحميل مساعد الذكاء الاصطناعي الخاص بك لتحميل الخادم الجديد

### حزم SDK المتاحة

يمكن بناء خوادم MCP باستخدام:
- **TypeScript/JavaScript** (الأكثر شيوعاً)
- **Python** (تغطية واسعة)
- **Go** (التركيز على البنية التحتية)
- **Rust** (حرج للأداء)
- **C#** (نظام .NET البيئي)
- **Java/Kotlin** (المؤسسات)
- **Ruby** (الأنظمة القديمة)
- **Swift** (iOS/macOS)
- **PHP** (تطبيقات الويب)

## إنشاء خوادم MCP مخصصة

### البدء السريع (TypeScript)

```typescript
import { Server } from "@modelcontextprotocol/sdk/server/index.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";

const server = new Server({
  name: "my-custom-server",
  version: "1.0.0",
});

// تسجيل الأدوات
server.setRequestHandler("tools/list", async () => ({
  tools: [{
    name: "my_tool",
    description: "وصف ما تفعله هذه الأداة",
    inputSchema: {
      type: "object",
      properties: {
        param: { type: "string", description: "وصف المعامل" }
      }
    }
  }]
}));

// التعامل مع استدعاءات الأدوات
server.setRequestHandler("tools/call", async (request) => {
  // التنفيذ
});

const transport = new StdioServerTransport();
await server.connect(transport);
```
