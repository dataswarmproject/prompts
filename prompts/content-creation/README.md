## Blog Posts and Articles

### Comprehensive Blog Post

```
Write a comprehensive blog post about [topic]

Target Audience: [who will read this]
Goal: [inform/persuade/entertain/convert]
Tone: [professional/casual/technical/friendly]
Length: [word count]

Requirements:
- Compelling headline that [benefit]
- Hook that grabs attention in first paragraph
- Clear structure with subheadings
- Practical examples and actionable takeaways
- Include statistics or data where relevant
- Strong conclusion with call-to-action

SEO Keywords: [primary keyword], [secondary keywords]

Structure:
1. Introduction (why this matters)
2. [Main point 1]
3. [Main point 2]
4. [Main point 3]
5. Conclusion and next steps

Format: Markdown with proper headings
```

### Thought Leadership Article

```
You are a recognized expert in [industry/field].

Write a thought leadership article about [topic/trend].

Your perspective:
- [Your unique insight or experience]
- [Contrarian view or fresh angle]

Goals:
- Establish authority and credibility
- Provide unique insights not found elsewhere
- Spark discussion and engagement
- Position as an industry leader

Include:
- Compelling thesis statement
- Personal anecdotes or case studies
- Data and research to support claims
- Future predictions or recommendations
- Discussion of trade-offs and nuance

Length: 1500-2000 words
Tone: Authoritative yet accessible
```

### How-To Guide

```
Create a step-by-step how-to guide for [task/process]

Audience Expertise: [beginner/intermediate/advanced]
Goal: Enable readers to [specific outcome]

Requirements:
- Clear, actionable title: "How to [achieve result]"
- Introduction explaining benefits and prerequisites
- Numbered steps with clear instructions
- Screenshots or descriptions of what to look for (specify where)
- Common pitfalls and how to avoid them
- Troubleshooting section
- FAQ section
- Time estimate for completion
- Required tools or resources

Format each step as:
Step X: [Action]
- What to do
- Why it matters
- Expected outcome
- [Screenshot description if needed]
```

## Social Media

### Multi-Platform Campaign

```
Create a social media campaign for [product/event/announcement]

Campaign Goal: [awareness/engagement/conversion]
Duration: [timeframe]
Budget: [if relevant]

Platforms:
- Twitter/X: [followers, engagement rate]
- LinkedIn: [followers, engagement rate]
- Instagram: [followers, engagement rate]
- Facebook: [followers, engagement rate]

For each platform, provide:
1. 5-7 posts with optimal timing
2. Platform-specific content (threads, carousels, etc.)
3. Hashtag strategy
4. Visual descriptions needed
5. Engagement tactics (polls, questions, CTAs)
6. Success metrics to track

Brand voice: [voice description]
Target audience: [demographics, interests]

Include:
- Launch announcement posts
- Educational/value posts
- Engagement posts
- Conversion posts
- User-generated content ideas
```

### Viral Thread Structure

```
Write a Twitter/X thread about [topic] optimized for engagement and virality.

Hook: [Your main compelling insight or question]

Target: [Your ideal audience]

Thread Structure:
1. Hook tweet (make them want to read more)
2. Setup (why this matters)
3-8. Main content (one idea per tweet)
9. Summary
10. CTA (follow, share, link)

Requirements:
- First tweet must stop the scroll
- Each tweet should provide value independently
- Use line breaks for readability
- Include relevant emojis (not excessive)
- One tweet should be "quotable" (screenshot-worthy)
- End with clear call-to-action
- Suggest image/gif opportunities

Tone: [conversational/authoritative/entertaining]
```

### Instagram Caption

```
Write an Instagram caption for [content type]

Post Description: [what's in the image/video]

Brand: [brand name and voice]
Goal: [engagement/awareness/sales]

Requirements:
- Hook in first line (before "more" cutoff)
- Story or value in middle
- Call-to-action
- Strategic hashtags (mix of broad and niche)
- Emoji usage (natural, not excessive)
- Length: [short: <50 words / medium: 50-125 / long: 125+]

Hashtag strategy:
- 3-5 branded hashtags
- 5-10 community hashtags
- 10-15 discovery hashtags
- Total: 20-30 hashtags

Include question or CTA to boost engagement.
```

## Marketing Copy

### Landing Page Copy

```
Write conversion-focused landing page copy for [product/service]

Product: [description]
Target Audience: [demographics, pain points, goals]
Unique Value Proposition: [what makes it different]

Sections needed:
1. Hero section:
   - Headline (benefit-driven, <10 words)
   - Subheadline (expand on benefit)
   - Primary CTA button text

2. Problem section:
   - Agitate the pain point
   - Show you understand their struggle

3. Solution section:
   - How your product solves it
   - Key features (3-5) with benefits

4. Social proof:
   - Testimonial suggestions
   - Trust indicators to highlight

5. How it works:
   - 3-step process
   - Keep it simple

6. Objection handling:
   - Address 3-5 common objections

7. Final CTA:
   - Compelling offer
   - Urgency/scarcity element
   - Risk reversal (guarantee)

Tone: [Conversational/Professional/Exciting]
Conversion goal: [Sign up/Purchase/Demo request]
```

### Product Description

```
Write a compelling product description for [product name]

Product details:
- Category: [what it is]
- Key features: [list features]
- Benefits: [how it helps]
- Price point: [budget/mid/premium]

Target customer:
- Who: [demographics]
- Pain points: [what they struggle with]
- Desires: [what they want]

Requirements:
- Headline that emphasizes main benefit
- Opening paragraph that hooks emotionally
- Features translated into benefits
- Sensory language and vivid descriptions
- Address objections preemptively
- Create desire and urgency
- Clear CTA

Length: [150-300 words for web / 50-100 for marketplace]
Tone: [brand voice]
SEO keywords: [keywords to naturally incorporate]
```

### Sales Email

```
Write a sales email for [product/service] to [audience]

Email sequence position: [1st touch / follow-up / re-engagement]

Prospect situation:
- [What you know about them]
- [Their likely pain point]
- [Why now is a good time]

Email requirements:
- Subject line (5-7 words, curiosity or benefit)
- Preview text (extends subject line)
- Personalized opening (reference something specific)
- One clear value proposition
- Social proof or credibility indicator
- Single, clear CTA
- PS line (alternative CTA or added benefit)

Length: 100-150 words max
Tone: Helpful, not salesy
Goal: [Book meeting / Start trial / Get response]

Avoid:
- Multiple CTAs
- Industry jargon
- Talking about your company too much
- Being pushy
```

## Email Campaigns

### Newsletter Template

```
Create an email newsletter for [company/topic]

Newsletter name: [name]
Audience: [subscriber profile]
Frequency: [weekly/biweekly/monthly]
Main goal: [educate/engage/sell]

This issue's theme: [theme]

Structure:
1. Subject line (intrigue or value)
2. Preheader text
3. Personal greeting
4. Main story/article (300-500 words)
5. Secondary content (2-3 brief sections):
   - [Section 1 type]
   - [Section 2 type]
   - [Section 3 type]
6. Resource/link of the week
7. CTA (primary action you want)
8. Footer/PS

Tone: [brand voice]
Template style: [text-only / HTML with images]

Make it:
- Scannable (short paragraphs, bullets, subheadings)
- Personal (write like 1-on-1 conversation)
- Valuable (clear takeaway or benefit)
```

### Welcome Email Series

```
Create a welcome email series for new [customers/subscribers]

Audience: People who just [signed up/purchased/downloaded]

Series length: [3/5/7 emails]
Timing: [Day 1, Day 3, Day 7, etc.]

For each email provide:
- Subject line
- Preview text
- Email body (200-300 words)
- Primary CTA
- Goal of this email

Email 1 (Immediate):
- Welcome and thank you
- Set expectations
- Quick win or immediate value
- Introduce yourself/brand

Email 2 (Day 2-3):
- Deliver promised value
- Education about [product/topic]
- Share helpful resources

Email 3 (Day 5-7):
- Success stories or use cases
- Overcome common obstacles
- Invitation to engage further

[Additional emails as specified]

Tone: Warm, helpful, welcoming
Avoid: Information overload, too salesy
```

## Video Scripts

### YouTube Video Script

```
Write a YouTube video script about [topic]

Video type: [Tutorial/Review/Vlog/Educational/Entertainment]
Length: [5/10/15/20 minutes]
Target audience: [viewer profile]

Video goals:
- [Primary goal: educate/entertain/convert]
- Target retention: [percentage]
- Target CTR: [percentage]

Script sections:

1. HOOK (0:00-0:15):
   - Grab attention immediately
   - Promise value/outcome
   - Create curiosity gap

2. INTRO (0:15-0:45):
   - Who you are (brief)
   - What this video covers
   - Why they should watch
   - CTA: Like and subscribe

3. MAIN CONTENT (bulk of video):
   - [Section 1 with timing]
   - [Section 2 with timing]
   - [Section 3 with timing]
   - Pattern interrupts every 2-3 minutes
   - Visual cues: [what to show on screen]

4. CONCLUSION (last 1-2 minutes):
   - Recap key points
   - Call-to-action (clear next step)
   - End screen suggestions

5. NOTES:
   - B-roll suggestions
   - Graphics needed
   - Music mood changes
   - Thumbnail concept

SEO:
- Title: [optimized title]
- Description: [first 150 characters]
- Tags: [relevant tags]

Tone: [energetic/calm/professional/casual]
```

### Explainer Video Script

```
Create an explainer video script for [product/concept]

Video length: 60-90 seconds
Goal: [understanding/interest/conversion]

Script structure:

SCENE 1 (0-15s): The Problem
- Visual: [description]
- Narration: [text]
- Emotion: Frustration/pain

SCENE 2 (15-30s): The Solution
- Visual: [description]
- Narration: [text]
- Emotion: Hope/relief

SCENE 3 (30-60s): How It Works
- Visual: [description]
- Narration: [text]
- Show 3 simple steps

SCENE 4 (60-75s): The Benefit
- Visual: [description]
- Narration: [text]
- Emotion: Success/happiness

SCENE 5 (75-90s): Call-to-Action
- Visual: [description]
- Narration: [text]
- Clear next step

Requirements:
- Simple language (6th-grade reading level)
- Active voice
- One idea per scene
- Smooth transitions
- Memorable tagline

Animation style: [2D/whiteboard/motion graphics]
```

## SEO Content

### SEO-Optimized Article

```
Write an SEO-optimized article for the keyword: [primary keyword]

Search intent: [informational/navigational/commercial/transactional]
Current SERP analysis: [what's ranking now]
Content gap to fill: [what's missing from current results]

Article specifications:
- Target word count: [1500-2500 words]
- Reading level: [target audience level]
- Keyword density: 1-2% natural integration

On-page SEO:
- Title tag (< 60 characters, include keyword)
- Meta description (< 160 characters, compelling)
- URL slug (short, keyword-focused)
- H1 (primary keyword, engaging)
- H2s and H3s (LSI keywords, structure content)
- Image alt text suggestions (5-7 images)

Secondary keywords to include naturally:
- [keyword 1]
- [keyword 2]
- [keyword 3]

Content requirements:
- Answer the primary query in first 100 words
- Include FAQ section (use People Also Ask questions)
- Add statistics and data (with source placeholders)
- Internal linking opportunities (mention 3-5)
- External linking (authoritative sources)
- Structured data recommendations

Make it:
- Comprehensive (cover topic thoroughly)
- Authoritative (demonstrate expertise)
- Readable (short paragraphs, bullets, visuals)
- Actionable (give clear next steps)
```

## Brand Voice

### Brand Voice Development

```
Develop a comprehensive brand voice guide for [company/brand]

Brand basics:
- Industry: [industry]
- Target audience: [description]
- Brand personality: [3-5 adjectives]
- Brand mission: [purpose]
- Competitors: [main competitors and their voice]

Create:
1. Voice attributes (4-5 core characteristics)
   For each: Definition, Do's, Don'ts, Examples

2. Tone variations for contexts:
   - Social media
   - Customer service
   - Marketing copy
   - Technical documentation
   - Email
   - Crisis communication

3. Word bank:
   - Words we use
   - Words we avoid
   - Phrases that sound like us

4. Grammar and style rules:
   - Contractions?
   - Punctuation style
   - Emoji usage
   - Formatting preferences

5. Example rewrites:
   Take generic messages and rewrite in brand voice:
   - "Thank you for your purchase"
   - "We encountered an error"
   - "Introducing our new feature"
   - "We're hiring"

6. Voice consistency checklist

Goal: Any team member should be able to write in brand voice after reading this.
```

### Content Repurposing

```
Repurpose this content across multiple formats:

Original content:
[Paste your content - blog post, video script, presentation, etc.]

Create versions for:
1. Twitter/X thread (8-10 tweets)
2. LinkedIn post (1300 characters)
3. Instagram carousel (6-8 slides with captions)
4. Email newsletter section (200-300 words)
5. YouTube video outline (10-minute video)
6. Infographic content (key stats and takeaways)
7. Podcast talking points (15-minute segment)

For each format:
- Adapt tone for platform
- Optimize for platform's best practices
- Maintain core message
- Include appropriate CTAs
- Suggest visual elements

Goal: Maximize reach while maintaining message consistency
```

## Quick Tips

1. **Know Your Audience**: Always specify who you're writing for
2. **Define Success**: What action do you want readers to take?
3. **Set the Tone**: Match voice to audience and platform
4. **Provide Examples**: Show desired style or structure
5. **Include Constraints**: Word count, keywords, format requirements
6. **Ask for Alternatives**: Get multiple headline or CTA options
