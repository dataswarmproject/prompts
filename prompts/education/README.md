## Curriculum Design

### Course Outline

```
Design a comprehensive course outline for [subject/topic]

Course details:
- Subject: [topic]
- Level: [K-12 grade / undergraduate / graduate / professional]
- Duration: [weeks/semester]
- Format: [in-person / online / hybrid]
- Meeting frequency: [times per week, duration]

Learning context:
- Prerequisites: [prior knowledge needed]
- Student profile: [typical student characteristics]
- Class size: [number of students]

Create:
1. Course overview:
   - Course description (2-3 paragraphs)
   - Course goals (3-5 broad goals)
   - Learning outcomes (8-12 specific, measurable outcomes)

2. Weekly/Module structure:

   Week 1: [Topic]
   - Learning objectives (specific)
   - Topics covered
   - Activities/methods
   - Readings/materials
   - Assignments
   - Assessments

   [Repeat for each week/module]

3. Assessment structure:
   - Formative assessments: [types and frequency]
   - Summative assessments: [major assessments]
   - Grading breakdown: [percentages]

4. Required materials:
   - Textbook(s)
   - Readings
   - Technology/tools
   - Supplies

5. Course policies:
   - Attendance
   - Late work
   - Academic integrity
   - Accessibility accommodations

6. Schedule of topics (table format):
   | Week | Date | Topic | Assignment Due |

7. Alignment matrix:
   Show how activities and assessments align with learning outcomes

Format: Syllabus-ready
```

### Learning Module Design

```
Design a learning module on [specific topic]

Module context:
- Topic: [specific subject]
- Target learners: [age/level/background]
- Duration: [time to complete]
- Delivery: [online/in-person/hybrid]
- Place in curriculum: [standalone/part of course]

Create:
1. Module overview:
   - Title
   - Description
   - Why this matters (relevance)

2. Learning objectives (3-5):
   - Use measurable verbs (Bloom's taxonomy)
   - By the end, learners will be able to...

3. Content structure:

   Section 1: [Title]
   - Key concepts
   - Content delivery method
   - Estimated time
   - Student activities
   - Checks for understanding

   Section 2: [Title]
   - [Same structure]

   [Continue for 3-5 sections]

4. Instructional strategies:
   - How to introduce topic
   - How to explain concepts
   - Practice opportunities
   - Application activities
   - Differentiation for diverse learners

5. Resources and materials:
   - What instructor needs
   - What students need
   - Technology required
   - Supplementary resources

6. Assessment:
   - Formative (during module)
   - Summative (end of module)
   - Rubric or success criteria

7. Scaffolding:
   - How to support struggling learners
   - How to extend for advanced learners

8. Engagement strategies:
   - How to maintain interest
   - Active learning elements
   - Collaborative elements

Align with: [Common Core/Next Gen Science/other standards]
```

## Lesson Planning

### Detailed Lesson Plan

```
Create a detailed lesson plan for [specific topic]

Lesson details:
- Topic: [specific lesson topic]
- Grade level: [grade or age]
- Duration: [minutes]
- Class size: [number of students]
- Setting: [classroom type]

Student context:
- Prior knowledge: [what they know]
- Learning needs: [special considerations]
- Class dynamics: [relevant factors]

Lesson plan:

1. Header:
   - Subject, grade, date
   - Standards addressed
   - Learning objective(s) - specific and measurable

2. Materials:
   - Teacher materials
   - Student materials
   - Technology
   - Handouts

3. Preparation:
   - Room setup
   - Pre-lesson tasks

4. Introduction/Hook (5 min):
   - Attention grabber
   - Connect to prior knowledge
   - State learning objective
   - Preview the lesson

5. Direct Instruction (X min):
   - Concepts to teach
   - Explanation method
   - Examples to use
   - Modeling
   - Think-aloud
   - Visual aids

6. Guided Practice (X min):
   - Activity description
   - Teacher role
   - Student actions
   - Checkpoints
   - Questions to ask
   - Feedback strategy

7. Independent Practice (X min):
   - Task description
   - Success criteria
   - Monitoring approach
   - Support for struggling students

8. Closure (5 min):
   - Summarize key points
   - Check for understanding
   - Connect to future lessons
   - Exit ticket or reflection

9. Assessment:
   - Formative assessments during lesson
   - How to check understanding
   - What to look/listen for

10. Differentiation:
    - For struggling learners
    - For advanced learners
    - For ELL students
    - For students with IEPs

11. Extension:
    - If time remains
    - Homework
    - Next lesson connection

12. Reflection notes:
    - What went well
    - What to change
    - Student understanding
    - Next steps

Teaching method: [direct instruction/inquiry/collaborative/etc.]
```

### Interactive Activity Design

```
Design an engaging learning activity for [topic]

Activity goal: [what students will learn/practice]
Topic: [specific content]
Level: [grade or age]
Duration: [minutes]
Class size: [number]
Format: [individual/pairs/small group/whole class]

Design:
1. Activity overview:
   - Name/title
   - Brief description
   - Learning objective

2. Materials needed:
   - List everything needed
   - Preparation required

3. Setup:
   - Room arrangement
   - Grouping strategy
   - Time for setup

4. Step-by-step instructions:

   For teacher:
   - How to introduce activity
   - How to give directions
   - How to model if needed

   For students:
   - Step 1: [clear instructions]
   - Step 2: [clear instructions]
   - [Continue...]

5. Student roles (if group work):
   - Role 1: [responsibilities]
   - Role 2: [responsibilities]

6. Teacher's role during activity:
   - Monitoring approach
   - Questions to ask
   - Interventions if needed

7. Time management:
   - Activity phase 1: [X minutes]
   - Activity phase 2: [X minutes]
   - Wrap-up: [X minutes]

8. Engagement strategies:
   - How to keep all students involved
   - Accountability measures

9. Debrief/Process:
   - Discussion questions
   - Reflection prompts
   - Connection to learning goals

10. Assessment:
    - What to observe
    - How to assess learning
    - Documentation method

11. Variations:
    - Easier version
    - More challenging version
    - Virtual adaptation

12. Common issues and solutions:
    - Problem 1: [and how to handle]
    - Problem 2: [and how to handle]

Make it: Engaging, inclusive, purposeful
```

## Assessment

### Rubric Design

```
Create a rubric for assessing [assignment/project]

Assignment: [description]
Learning objectives being assessed:
- [Objective 1]
- [Objective 2]
- [Objective 3]

Level: [grade or course level]
Type: [holistic/analytic]

Design rubric:

1. Criteria (4-6 key dimensions):

   Criterion 1: [e.g., Content Knowledge]
   Weight: [points or percentage]

   Criterion 2: [e.g., Critical Thinking]
   Weight: [points or percentage]

   [Continue for each criterion]

2. Performance levels:
   - Exemplary (4)
   - Proficient (3)
   - Developing (2)
   - Beginning (1)

3. For each criterion and level, describe:

   [Criterion 1]:
   - Exemplary (4): [specific, observable descriptors]
   - Proficient (3): [specific, observable descriptors]
   - Developing (2): [specific, observable descriptors]
   - Beginning (1): [specific, observable descriptors]

   [Repeat for all criteria]

4. Rubric characteristics:
   - Descriptors are clear and specific
   - Differences between levels are distinct
   - Language is student-friendly
   - Focuses on quality, not quantity where appropriate
   - Aligned with learning objectives

5. Student version:
   - Simplified language if needed
   - Self-assessment column

6. Point distribution:
   - Total possible points
   - Points per criterion
   - Conversion to grade

Format: Table ready to share with students
Purpose: Clear expectations and consistent grading
```

### Assessment Suite

```
Design a comprehensive assessment plan for [unit/topic]

Unit: [title]
Duration: [length]
Level: [grade]
Learning objectives: [list main objectives]

Create:
1. Pre-assessment:
   - Type: [quiz/discussion/survey]
   - Purpose: Gauge prior knowledge
   - Key questions (5-10)
   - How to use results

2. Formative assessments (ongoing):

   Check 1 (Lesson X):
   - Format: [exit ticket/quick quiz/thumbs up]
   - What it measures
   - Questions/prompts
   - How to respond to results

   Check 2 (Lesson Y):
   - [Same structure]

   [3-5 formative assessments]

3. Summative assessment(s):

   Assessment 1: [type]
   - What it measures
   - Format description
   - Student instructions
   - Rubric or answer key
   - Points/grade weight

   [Additional summative assessments if needed]

4. Assessment variety:
   - Traditional: [quizzes, tests]
   - Performance: [demonstrations, presentations]
   - Product: [projects, portfolios]
   - Process: [observations, conferences]

5. Accommodations:
   - For ELL students
   - For students with IEPs
   - For struggling students
   - For advanced students

6. Grading breakdown:
   - Formative: [%]
   - Summative: [%]
   - Participation: [%]
   - Total: 100%

7. Feedback strategy:
   - When students receive feedback
   - Type of feedback (written/verbal/both)
   - Revision opportunities

8. Data tracking:
   - How to record results
   - What to track
   - How to identify patterns

9. Response to data:
   - If most students struggle: [instructional adjustment]
   - If individual students struggle: [intervention]
   - If students exceed expectations: [enrichment]

Goal: Multiple measures of learning, actionable data
```

## Student Support

### Differentiation Strategy

```
Create differentiation strategies for [lesson/unit]

Lesson: [topic]
Grade: [level]
Standards: [what you're teaching to]

Class profile:
- Total students: [n]
- Reading levels: [range]
- Special needs: [IEPs, 504s, ELL]
- Gifted students: [number]
- Learning preferences: [variety in class]

Differentiate by:

1. Content (what students learn):

   Struggling learners:
   - Simplified texts
   - Visual supports
   - Pre-teaching vocabulary
   - Concrete examples
   - Modified objectives: [still rigorous but accessible]

   On-level learners:
   - Grade-level materials
   - Standard objectives

   Advanced learners:
   - Complex texts
   - Additional concepts
   - Extension objectives: [deeper/broader]

2. Process (how students learn):

   Struggling learners:
   - More scaffolding
   - Step-by-step guides
   - Teacher-led small group
   - Graphic organizers
   - Additional practice time

   On-level learners:
   - Moderate scaffolding
   - Collaborative learning
   - Standard pacing

   Advanced learners:
   - Minimal scaffolding
   - Independent investigation
   - Faster pacing
   - Open-ended challenges

3. Product (how students demonstrate learning):

   Struggling learners:
   - Supported formats
   - Clear models
   - Rubrics with examples
   - Options: [list alternative products]

   On-level learners:
   - Standard format
   - Clear rubric
   - Some choice

   Advanced learners:
   - Open-ended format
   - Student choice
   - Higher complexity
   - Options: [list advanced products]

4. Learning environment:
   - Flexible seating options
   - Quiet work spaces
   - Collaborative areas
   - Access to resources

5. Grouping strategies:
   - When to use homogeneous groups (skill building)
   - When to use heterogeneous groups (collaboration)
   - Flexible grouping based on task

6. Support strategies:
   - For ELL: [specific supports]
   - For students with disabilities: [accommodations]
   - For gifted: [enrichment]

7. Ongoing assessment:
   - How to monitor each group
   - When to adjust groups
   - When to adjust strategies

Remember: High expectations for all, varied paths to get there
```

### Intervention Plan

```
Design an intervention plan for [skill/subject area]

Student profile:
- Grade: [level]
- Current performance: [specific data]
- Goal: [where they need to be]
- Gap: [specific skills lacking]

Intervention design:

1. Skill focus (prioritize):
   - Primary skill: [most critical]
   - Secondary skills: [supporting skills]

2. Assessment:
   - Diagnostic: [to pinpoint exact needs]
   - Progress monitoring: [quick weekly check]
   - Mastery check: [when to reassess]

3. Intervention structure:
   - Duration: [how many weeks]
   - Frequency: [times per week]
   - Session length: [minutes]
   - Group size: [1-on-1 or small group]
   - Delivered by: [teacher/aide/specialist]

4. Instructional approach:
   - Teaching method: [explicit instruction/guided practice/etc.]
   - Evidence-based strategies for this skill
   - Sequence of instruction
   - Materials needed

5. Session structure:
   Minutes 1-5: [activity]
   - Purpose
   - What teacher does
   - What student does

   Minutes 6-15: [activity]
   - [Same structure]

   Minutes 16-20: [activity]
   - [Same structure]

6. Scaffolding plan:
   Week 1-2: [high support - what it looks like]
   Week 3-4: [medium support - fading scaffolds]
   Week 5-6: [low support - independence]

7. Progress monitoring:
   - Measure: [specific assessment]
   - Frequency: [weekly/biweekly]
   - Data tracking system
   - Goal line: [rate of improvement needed]
   - Decision rules:
     - If adequate progress: [continue]
     - If inadequate progress: [intensify]
     - If mastery: [exit intervention]

8. Parent communication:
   - Initial notification
   - Progress updates (frequency)
   - Home practice suggestions

9. Generalization plan:
   - How to apply to classroom work
   - Support for transfer

10. Exit criteria:
    - Performance level needed
    - Consistency required
    - Post-intervention support

Data-driven, explicit, intensive, targeted
```

## Educational Content

### Explainer Script

```
Write an educational explainer for [concept]

Concept: [topic to explain]
Audience: [age/grade level]
Prior knowledge: [what they already know]
Duration: [minutes if video, words if text]
Format: [video script/text article/podcast script]

Create:

1. Hook (30 seconds / 50 words):
   - Grab attention
   - Connect to student interest
   - Pose intriguing question

2. Context (1 min / 100 words):
   - Why this matters
   - Real-world relevance
   - What we'll learn

3. Explain the concept:

   Part 1: [Sub-concept A]
   - Simple definition
   - Clear explanation
   - Analogy or metaphor
   - Visual description (what to show)
   - Example 1
   - Example 2

   Part 2: [Sub-concept B]
   - [Same structure]

   Part 3: [Sub-concept C]
   - [Same structure]

4. Common misconceptions:
   - Misconception 1: [explain why it's wrong]
   - Misconception 2: [explain correct understanding]

5. Application/Practice:
   - "Now you try..." prompt
   - Interactive element
   - Think-aloud example

6. Summary:
   - Key takeaways (3-5 bullets)
   - Reinforce main concept

7. Connection:
   - Where this fits in bigger picture
   - What comes next
   - Further exploration

Style:
- Conversational but clear
- Age-appropriate vocabulary
- Short sentences
- Active voice
- Engaging tone

Include:
- Definitions highlighted
- Key terms
- Visual cues
- Pacing notes (for video)
```

### Study Guide

```
Create a comprehensive study guide for [unit/test]

Unit: [title]
Content covered: [topics]
Level: [grade]
Test format: [multiple choice, essay, mixed, etc.]

Study guide sections:

1. Overview:
   - What this unit covered
   - Why it matters
   - Learning objectives

2. Key concepts (organized by topic):

   Topic 1: [Name]
   - Main ideas (3-5)
   - Important terms with definitions
   - Key facts to remember

   Topic 2: [Name]
   - [Same structure]

   [Continue for all topics]

3. Essential vocabulary:
   - Term 1: Definition
   - Term 2: Definition
   [15-25 key terms]

4. Important people/dates/events (if applicable):
   - [Organized list with key info]

5. Connections:
   - How concepts relate
   - Cause and effect relationships
   - Compare and contrast

6. Study strategies:
   - How to study this material
   - Recommended study sequence
   - Time allocation suggestions

7. Practice questions:

   Multiple choice (if applicable):
   - [10-20 questions with answers]

   Short answer:
   - [5-10 questions that might appear]
   - What to include in answers

   Essay prompts:
   - [Possible prompts]
   - Essay structure suggestions
   - Key points to address

8. Visual aids:
   - Important diagrams (descriptions)
   - Charts to memorize
   - Graphic organizers

9. Common mistakes to avoid:
   - [Mistake 1 and why]
   - [Mistake 2 and why]

10. Test-taking tips:
    - Format-specific strategies
    - Time management
    - What to bring

11. Resources:
    - Textbook pages
    - Notes from [dates]
    - Additional resources
    - Office hours for questions

12. Self-check:
    - Can you... [checkpoint questions]
    - If no, review [where]

Format: Clean, organized, scannable
```
