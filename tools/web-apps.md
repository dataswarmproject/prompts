**Web-based AI tools and browser extensions for enhanced productivity.**

## General AI Assistants

### 1. ChatGPT (Web)

**URL**: https://chat.openai.com

**Key Features**:
- GPT-4 Turbo and GPT-3.5 access
- Image generation (DALL-E)
- Code interpreter
- File uploads (PDFs, images, documents)
- Custom GPTs
- Browsing capability
- Voice conversations

**Plans**:
- Free: GPT-3.5, limited GPT-4
- Plus ($20/mo): GPT-4, priority access, custom GPTs
- Team ($25/user/mo): Team workspace, admin controls
- Enterprise: Custom pricing, enhanced security

**Best For**:
- General queries
- Brainstorming
- Code help
- Content creation
- Data analysis

## Setup Tips

### Browser Extension Workflow

1. Install primary assistant (Monica or Merlin)
2. Add specialized tools as needed
3. Configure keyboard shortcuts
4. Set default AI models
5. Organize by use case

### Cost Optimization

- **Free tier strategy**: Rotate between free tiers
- **Shared subscriptions**: Team plans for groups
- **Pay for what you use**: API access for power users
- **Bundle deals**: Look for multi-tool packages

### Privacy Considerations

- Review data policies
- Use incognito for sensitive work
- Avoid sharing confidential information
- Consider self-hosted alternatives for sensitive data
